# 首轮微调用验证候选

四个标准各 2 条，共 8 条。四个机制在生成前已登记为 `validation_groups`，都没有出现在 16 条训练候选或 20 道开发题中。它们用于首轮冒烟时观察验证损失和错误；题量很小，不是最终测试集，也不参与训练。

- **H.264**：亮度水平分数像素插值。物理页 197，式 (8-241)、(8-243)、(8-250)。核对半像素必须先归一化、裁剪，再进入四分之一像素平均；8-bit 计算例的半像素为 255、四分之一像素为 248。该题只讨论水平路径。
- **H.265**：CTB 的全图栅格扫描与 tile scan。物理页 46–47 的 6.5.1，以及物理页 113 的 `slice_segment_address` 语义。核对 5×3 CTB 网格的非对称 tile 排列；RS 10 转为 TS 7，TS 11 转为 RS 9。
- **H.266**：独立子图与跨边界滤波。物理页 55 的 SPS 条件分支和物理页 120–121 的语义。核对独立子图开启时不读取两个逐子图标志，缺省为 1、0；允许跨界与实际发生滤波分开解释。
- **AV1**：胶片颗粒语法和参数复用。物理页 69 的 5.9.30。核对不可显示帧的提前返回，以及复用参考参数时保存并恢复当前帧的种子 321。

公式、扫描顺序和标志语义对照了锁定的规范及相应 PDF 页面。题面、参考答案、证据哈希在 `candidates.jsonl`；四个数值/派生案例在 `numeric-cases.json`。核验脚本实际复算结果保存在 `verification-report.json`。

在仓库根目录，恢复来源后可以复验：

```bash
python3 scripts/verify_validation_batch.py
```

脚本会同时检查训练候选、验证候选与开发题的显式重合，并拒绝验证组转入训练分片。此批 `verification.status` 和 `eligibility.status` 仍是 `pending`。独立领域复核通过后，才将通过的训练和验证样本合并为审核输入，由 `prepare_training.py` 按注册组导出 `train.jsonl` 和 `valid.jsonl`。最终测试仍需独立准备。
