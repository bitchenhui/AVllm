# 最终测试 v1：独立小样本草案

第一批草案共 8 道，四标准各 2 道，含 4 道可复算题。H.264 保留 frame_num 间隙与参考图像管理；H.265 保留显式加权样本预测；H.266 保留 AMVR 与 MVD 精度；AV1 保留主参考与 CDF 状态。先登记家族，再生成题面。

题面和评分键分开存放在本地 `data/holdout/v1-draft/`，Git 只保存本说明、机制登记和文件哈希。训练机的 Git 副本无需持有测试题或答案。训练数据生成和模型配置选择都不使用这些文件；验证最终模型时，只把题面交给模型，评分键留在评测机。正式 A/B/C/D 评测按 [评测协议](../../docs/evaluation.md) 执行。

在持有私有副本及锁定来源的评测机上，运行：

```bash
python3 scripts/verify_holdout_draft.py
```

它会核验文件哈希、证据和数值参考，检查与现有训练候选、验证候选及开发题的题面、分组和证据重合。草案目前固定了文件版本，仍待独立领域复核；8 题只适合检查评测流程。发现需要改题或改评分点时建立新版本，保留现有哈希，不据此报告最终模型收益。
